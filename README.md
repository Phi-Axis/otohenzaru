# 発音変化スライム狩り

正解が確認済みの韓国語を次々に出すだけの練習アプリ。発音変化の解析・自動生成はしない。

## 公開（GitHub Pages）
1. このフォルダの中身をリポジトリに置く
2. Settings → Pages → Branch: `main` / `(root)` で保存

## 問題の追加
`data/questions.js` だけを編集する。書き方はファイル冒頭のコメント参照。
単独スライム狩りのカテゴリー一覧も同じファイルの `CATEGORIES` で決まる。

## 音声
音声ファイルを `audio/` に置き、問題に `audio: "audio/ファイル名.mp3"` を書き足す。
書いていない問題では 🔊 ボタンは出ない。
